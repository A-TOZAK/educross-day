# EDUCROSS in 北九州 2026 — 当日ページ

2026年8月1日（土）に小倉で開いた EDUCROSS in 北九州 の当日用サイト。

- `index.html` … 参加者が手元のスマホで開くページ（流れ・ふきだしくん・話の呼び水・おみやげ・LINE・アンケート）
- `slides.html` … 会場のスクリーンに映すスライド（16:9・←→キーでめくる・`f`で全画面）
- `data/sns.js` … 「今日つながった方」のSNS一覧。**本人が載せてよいと言ったものだけ**書く

公開URL: https://a-tozak.github.io/educross-day/

## 今日つながった方を追加するには

`data/sns.js` の `window.SNS_MEMBERS` に、ファイル冒頭のコメントの形でひとりぶんずつ足して、
commit して push すると数分でサイトに出ます。降ろすときはその人の `{ }` を丸ごと消す。

載せないもの: メールアドレス／勤務校の詳細／写真／本人の許可がないもの。
